Reaching the database

If it's local, use localhost directly. If it's remote, expose it with a free tunnel via Pinggy:

$ ssh -p 443 -R0:localhost:5432 tcp@a.pinggy.io  # PostgreSQL
$ ssh -p 443 -R0:localhost:3306 tcp@a.pinggy.io  # MySQL

Pinggy prints a link like tcp://tcp.free.pinggy.link:43215 — use tcp.free.pinggy.link as Host and 43215 as Port below. Only Postgres and MySQL are supported for discovery today; Oracle and MSSQL are a separate follow-on.

or connect a new database

Use a read-only database user for this connection if your database supports it.
