Jira & Confluence
Compare Buddy

Easily analyze your sites' configurations and compare stats across multiple environments in parallel.
01
Configure Credentials
From the sidebar, start by setting up your credentials. If you are using different credentials for multiple cloud sites, configure each site individually. Otherwise, just save a default credential for all sites.
02
Analyze & Compare
Select a platform from the sidebar to begin. You can run parallel, multi-site analysis to instantly compare project configurations, schemes, and general usage statistics.
03
Track Data Changes & Consolidations
From the Jira or Confluence general stats page, you can run an analysis and export the results as a JSON file. Later, you can upload that saved file back into the tool to compare historical data against your live site. This is the perfect for auditing data changes especially during instance consolidations.
04
Connect Local Databases
Because this tool is cloud-hosted, it cannot directly reach your local machine. If you want to analyze a local Data Center database, use a free secure tunnel via Pinggy. $ ssh -p 443 -R0:localhost:5432 tcp@a.pinggy.io // For PostgreSQL
$ ssh -p 443 -R0:localhost:3306 tcp@a.pinggy.io // For MySQL
Pinggy will output a TCP link (e.g., tcp://tcp.free.pinggy.link:43215). Enter tcp.free.pinggy.link as the Host and 43215 as the Port in your Credentials form.
Security Note: Only do this for temporary analysis. Close the Pinggy terminal immediately when finished to cut off public access to your database.
